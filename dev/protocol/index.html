Protocol & schemas

Understand the different representations before reaching for the exact contracts.

Four representations, different jobs

NWM3 messaging wire
ZeroMQ multipart binary frames carry commands, metadata, and an arbitrary byte payload. These frames are not a JSON document. The exact frame order, grammar, validation, and lifecycle are in the frozen NWM3 messaging specification.
Python and Node SDK messages
A received Message presents id, sender, network, payload, and optional reply_to to application code. Payload remains bytes; absent reply_to is None in Python and undefined in Node. See the API reference.
CLI events
Client and admin commands emit newline-delimited JSON. A message event has six keys: event, id, reply_to, network, sender, and payload. The payload is canonical base64; absent reply_to is JSON null. See the CLI reference for event types and exact input rules.
Relay configuration
Version 2 configuration is strict TOML, not the messaging wire or a message payload schema. It declares endpoints, limits, and network policy. See the configuration reference.

These representations are related, but they are not one universal JSON schema. Applications define their own payload format.

Administration is separate

NA1 administration uses a separate local endpoint and authority. Its operations and revision semantics are described in the administration reference; a practical walkthrough is in Run a relay. Administrator and network-join credentials grant distinct permissions, not peer identity.

Version compatibility

NodalWire 0.3.0 uses NWM3. Use matching Python and Node 0.3.0 packages with the relay; 0.2.x uses incompatible AR2 and cannot be mixed with them. NA1 administration and configuration version 2 are unchanged. The frozen specification retains its original development-planning context; package release versions and installation are described in Getting started.

Sending success is relay native per-destination queue acceptance—not proof of processing or durable storage. See Messaging for the practical meaning and timeout boundaries.
