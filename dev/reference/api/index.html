Client API reference

Python and Node.js message APIs for NodalWire 0.3.0.

Shared contracts

Use Python nodalwire==0.3.0 and Node @devcapsule/nodalwire-client@0.3.0 with the matching 0.3.0 relay. See Getting started for installation and availability. Older 0.2.x packages use incompatible AR2.

Names and networks match ASCII [A-Za-z0-9][A-Za-z0-9_.-]{0,127}. Endpoints are loopback-only TCP; the client default is tcp://127.0.0.1:5555. Registration admits a live name, not an authenticated identity. Open default autojoins; protected default starts with zero memberships. Nondefault networks always require explicit joins.

Every send selects one network; omitted means default, never fallback. Both peers must be members and directional route policy must permit the send. Credentials authorize joining, not peer identity.

Python

Import Node, Message, MembershipReceipt, RelayError, and ReceiptTimeout from nodalwire. Use the asynchronous factory rather than constructing a node without registration.

client.pypython
import asyncio
from nodalwire import Node

async def main():
    async with await Node.connect("alice") as alice:
        await alice.send("bob", b"hello", network="default")
        message = await asyncio.wait_for(alice.receive(), timeout=5)
        print(message.sender, message.network, message.payload)

asyncio.run(main())

This lifecycle fragment requires a connected Bob that replies; use the request/reply guide for the responder and round-trip flow.

await Node.connect(name, endpoint="tcp://127.0.0.1:5555", **options)
Waits for registration and starts owned reader/heartbeat tasks. Options: timeout=5.0 seconds, send_hwm=64, receive_hwm=64, inbox_size=64, max_pending=128. Queue limits are positive native integers; timeouts are finite and positive.
await node.join(network, credential=None, *, timeout=None)
Returns frozen MembershipReceipt(network, joined=True, changed=...). Open networks need no credential. Protected networks require their join credential; repeated joins recheck policy.
await node.leave(network, *, timeout=None)
Returns a receipt with joined=False. Other memberships remain. Repeated absence gives changed=False.
await node.send(destination, payload, *, network="default", reply_to=None, timeout=None)
Payload must be bytes, within the negotiated cap. Returns its generated id only after destination native queue acceptance.
await node.receive()
Returns frozen Message(id, sender, network, payload, reply_to=None); payload stays opaque bytes. Bound a wait using asyncio.wait_for or asyncio.timeout.
node.receive_nowait()
Removes one ordinary queued message, or returns None. It does not read native data or consume an active correlated reply.
await node.request(destination, payload, *, network="default", timeout=None)
Returns the whole native reply Message. Correlation matches reply_to, expected sender, and selected network; one deadline covers send acceptance and reply waiting.
await node.reply(incoming, payload, *, timeout=None)
Replies to any valid Message, targets its sender/network and sets reply_to=incoming.id. Returns a fresh accepted message ID; no network override.
await node.close(*, timeout=None)
Attempts release and always cleans up the owned socket/context/tasks. Failed release remains uncertain; the name may stay leased until expiry. Concurrent/repeated close waits for shared cleanup. Async context exit calls close.

Per-operation timeout=None uses the connection timeout. Invalid argument types/values raise TypeError/ValueError; relay/local protocol failures use RelayError.code. Cancellation uses Python's asyncio cancellation semantics and can follow an effect.

Node.js

The ESM package is @devcapsule/nodalwire-client@0.3.0 for Node.js 24. After publication, install it with npm install @devcapsule/nodalwire-client@0.3.0; before publication, use the verified local tarball. Consumers do not need a source checkout or TypeScript compiler. Save this fragment as client.mjs and run node client.mjs while a matching relay and responding Bob are connected.

client.mjsjavascript
import { Node } from "@devcapsule/nodalwire-client";

const endpoint = process.env.NODALWIRE_ENDPOINT ?? "tcp://127.0.0.1:5555";
const alice = await Node.connect("alice", endpoint);
try {
  await alice.send("bob", Uint8Array.of(0, 255));
  const message = await alice.receive({ signal: AbortSignal.timeout(5000) });
  console.log(message.sender, message.network, message.payload);
} finally {
  await alice.close();
}

This fragment likewise requires a responding Bob. Node.connect(name, endpoint?, options?) waits for registration. Options use camelCase: timeout=5 seconds, sendHwm=64, receiveHwm=64, inboxSize=64, maxPending=128, optional signal. Timeouts must also fit a native timer.

await node.join(network, credential?, options?) / await node.leave(network, options?)
Return readonly { network, joined, changed }. Options support timeout and signal.
await node.send(destination, payload, { network?, reply_to?, timeout?, signal? }?)
Accepts Uint8Array, including Buffer. Snapshots bytes synchronously, preserving subarray bounds; returns its generated ID on native queue acceptance.
await node.receive({ signal? }?) / node.receiveNowait()
Return readonly metadata { id, sender, network, payload, reply_to }, with reply_to set to undefined when absent; payload is caller-owned mutable bytes. Empty nonblocking receive returns undefined. Receive has no separate timeout option: use an abort signal.
await node.request(destination, payload, { network?, timeout?, signal? }?)
Returns the whole native Message. reply_to, sender, and network must match the pending request.
await node.reply(incoming, payload, { timeout?, signal? }?)
Replies to any valid message, returns a fresh accepted ID, and captures incoming metadata/ID and outgoing bytes before awaiting. Always uses the incoming network.
await node.close({ timeout?, signal? }?)
Attempts release, then joins native reader/writer cleanup even on timeout/cancellation. Only the first close caller controls the release deadline/cancellation.

timeout is seconds; AbortSignal.timeout takes milliseconds. Cancellation rejects with the signal's reason. Invalid encode/input arguments generally use TypeError; relay/local failures use RelayError.code. There is no Node administration API.

Breaking NWM3 migration

Version 0.3.0 is a breaking wire and API upgrade. Upgrade every messaging client and the relay together; do not mix NWM3 with AR2 clients/relays. NA1 administration and configuration version 2 remain unchanged.

Remove envelope imports and decoding. Read Message.payload directly; use the native id and reply_to metadata for application correlation. Consume the ID returned by successful send/reply. Old NWR1 bytes are never auto-detected or translated; as ordinary payload they count directly toward the byte limit. Regenerate saved CLI message files in the exact six-key format documented in the CLI reference. These changes are not a 0.2.x patch.

Errors, pressure, and lifecycle

Representative safe codes: admission_denied, duplicate_name, join_denied, network_not_found, not_member, destination_not_member, route_denied, destination_unavailable, destination_full, payload_too_large, pending_full, local_queue_full, closed, and connection_failed. Errors do not expose credential values.

ReceiptTimeout means effect uncertain. Send success is not receipt, execution, or durability. A matching application reply can win before a routing receipt; earlier failure/cancellation/deadline instead ends matching and leaves later data ordinary. No automatic retry, reconnect, or replay is supplied.

Drain ordinary messages concurrently with requests: a full inbox pauses the sole native reader and therefore reply/control progress. Receipt entries and reply waiters each have the pending cap. Node has no outbound backlog; a second in-flight native write can reject local_queue_full. HWM bounds message counts, not all memory.

Queued data survives close and remains readable; an empty closed receive fails with closed. Already accepted data may outlive leave/removal. Membership receipts are snapshots, not an authoritative local membership cache. For executable round trips and uncertainty rules see request/reply; for Python relay/admin APIs see configuration and administration.
