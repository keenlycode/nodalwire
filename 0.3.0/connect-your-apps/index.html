Connect your apps

Choose names, connect to one local relay, and agree on how your applications exchange bytes.

For Python applications, create a virtual environment and install nodalwire==0.3.0 into it. For Node.js 24 applications, install @devcapsule/nodalwire-client@0.3.0. Registry installation applies after publication; prepublication testing uses the matching verified local artifacts. The CLI's isolated tool installation is separate from your application's Python environment.

From a first exchange to your own apps

  1. Install matching 0.3.0 packages and try the first-message walkthrough in Get started.
  2. Pick a distinct live routing name for each connection. Connect to the same loopback relay and keep each connection open while it is needed.
  3. Join a common network and select it when sending. Open default joins automatically; every nondefault network and a protected default require explicit joins.
  4. Agree on payload encoding and application acknowledgements. NodalWire routes opaque bytes rather than defining your application format.
  5. Close each client when finished and handle uncertain outcomes without blindly retrying.

For exact Python and Node.js connection and cleanup methods, see the API reference. For send and request/reply examples, start with Messaging.

Networks and trust

Read networks and membership for open and protected examples, and security and local trust before sharing credentials. A network credential grants permission to join; it does not authenticate a peer's name. Bearer credentials do not encrypt local traffic.
