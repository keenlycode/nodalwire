Configuration reference

Strict version 2 startup configuration, declared network policies, and honest persistence boundaries.

Load a version 2 file

Start with .venv/bin/nodalwire serve --config local.toml. Set NODALWIRE_ADMIN_TOKEN explicitly before startup, as in Getting Started. This example deliberately contains no raw credential or verifier:

local.tomltoml
config_version = 2
revision = 0
endpoint = "tcp://127.0.0.1:5555"
admin_endpoint = "tcp://127.0.0.1:5556"
lease_seconds = 10.0
send_hwm = 64
receive_hwm = 64
max_payload_bytes = 1048576
allowed_names = ["alice", "bob", "observer"]
deny = [["@writers", "observer"]]

[routing_groups]
writers = ["alice", "bob"]

[networks.team]

default is added as open if omitted. The declared team network is also open, but peers must explicitly join it. writers is a static selector group, not a network membership list or an authenticated identity group. This rule denies Alice/Bob to Observer, not the reverse; unspecified routes are allowed.

load_config(Path(...)) returns an immutable RelayConfig. TOML must explicitly have integer config_version = 2; legacy configuration, unknown top-level fields, and unsupported network policy fields are rejected. Constructing RelayConfig() in Python defaults the version to 2.

Fields and defaults

config_version = 2
Required in TOML. No silent migration or legacy fallback.
revision = 0
Integer from 0 through 2**53 - 1. Successful configuration mutations advance it; exhausted revision cannot advance.
endpoint = "tcp://127.0.0.1:5555"
Peer data bind endpoint. Loopback literal IPv4/IPv6 or normalized localhost only; a wildcard port * is allowed for binds.
admin_endpoint = "tcp://127.0.0.1:5556"
Separate local administration bind endpoint with the same loopback validation. Use distinct data/admin addresses.
lease_seconds = 10.0
Finite number from 0.1 through 3600. Client heartbeats run approximately every lease/3; pressure may delay or skip them.
send_hwm = 64 / receive_hwm = 64
Positive native integers through 2**31 - 1. These bound message counts, not total bytes or all operating-system buffering.
max_payload_bytes = 1048576
Positive integer through 2**31 - 4096. Clients enforce the negotiated raw payload-byte cap. Native message metadata is outside that payload limit; base64 in CLI JSON is only an I/O representation.
allowed_names (omitted)
Omission allows any valid name at registration. An array restricts admission; an empty array admits none. Names are cooperative routing labels, not authenticated identities.
deny = []
Array of directional source/destination selector pairs. Select exact names, *, or @group; referenced groups must exist.
[routing_groups] (empty)
Maps valid static group names to arrays of valid routing names. No membership or identity authority is implied.
[networks.NAME]
Declares a network policy, open when empty. The only policy field is optional join_verifier. Network and node names use [A-Za-z0-9][A-Za-z0-9_.-]{0,127}.
admin_verifier (omitted)
Optional valid salted scrypt-v1 verifier. If absent, startup requires the explicit environment token. NODALWIRE_ADMIN_TOKEN, when present, takes precedence, including failing if malformed.

Configure protected networks

Python exposes NetworkConfig from nodalwire.config and make_verifier from nodalwire.credentials. This fragment constructs a protected default using a separately supplied join credential:

configuration.pypython
from nodalwire import RelayConfig
from nodalwire.config import NetworkConfig
from nodalwire.credentials import make_verifier

def protected_configuration(join_credential):
    return RelayConfig(networks={
        "default": NetworkConfig(join_verifier=make_verifier(join_credential)),
    })

For TOML, place a generated valid verifier in the policy's join_verifier, not the raw token. Protect the file and credential channel. Administrator and join credentials should be distinct. A protected default permits registration with zero memberships; it does not deny registration outright. See networks for explicit join flows.

Startup and runtime boundaries

Endpoints, admission/routing rules, groups, lease, and native limits are startup-only. Runtime administration can change network policies and a configuration-managed administrator verifier, not arbitrary startup fields. Membership is ephemeral and never serialized as network configuration.

The Python embedded API is Relay(config) or Relay(store=store), with ConfigStore from nodalwire.config_store for explicit file ownership. Entering a relay's async context binds its sockets; start relay.run() as an owned task, cancel and await that task before context exit. The bound relay.endpoint and relay.admin_endpoint expose selected ports for wildcard binds.

Persistence and revision conflicts

Without a configuration path, mutations update memory only. With serve --config, configuration mutations serialize the complete schema to a temporary file, fsync it, replace the same original path, and fsync the parent directory. Comments and original formatting are not preserved. A regular nonsymlink file is required; startup and commit validation guard the owned file.

Expected-revision checks prevent stale mutations. External-file fingerprint changes also produce a conflict rather than overwriting unseen edits; this is not a cross-process lock. Before replacement, persistence failure is no_effect. Failure after replacement can be persistence_indeterminate: the candidate is published in memory and the durability outcome remains uncertain. Re-read and reconcile; never blindly replay.

member.remove changes ephemeral membership, requires the current expected revision, and does not increment the configuration revision. Read operations return current revision plus redacted state. See administration for exact operation shapes and error handling.
