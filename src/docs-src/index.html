What is NodalWire?

NodalWire helps cooperating processes on the same machine exchange messages. Each application connects with a name; a relay routes its bytes to another named connection on a shared network. The relay does not interpret your application data.

Use it for local tools, agents, and small services that need an explicit routing boundary. It is not a remote-host transport, durable message store, or identity service.

Start here

  1. Get started: install NodalWire, start a local relay, and send your first message.
  2. Learn messaging: understand send, receive, and request/reply.
  3. Connect your apps or run a relay for your own workflow.

When you need exact signatures and formats, use the API reference and protocol and schemas.

Know the boundaries

  • A successful send means the relay accepted the data into the destination's native queue—not that Bob read or processed it, or that it was stored durably.
  • A timeout can occur after an effect. NodalWire does not automatically retry, reconnect, or replay; don't blindly retry a mutation.
  • Credentials grant permission, not authenticated identity. Local bearer credentials do not encrypt traffic; see security and local trust.

These docs target NodalWire 0.3.0, using matching Python and Node packages. Version 0.2.x uses incompatible AR2; upgrade clients and relay together. Follow Getting started for installation and release-availability guidance.
