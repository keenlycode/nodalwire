What it does—and does not promise

  • Python and Node.js clients exchange raw bytes through a matching NWM3 local development candidate.
  • Declared networks are open unless protected; a protected default needs an explicit join.
  • A successful send returns its message ID after native destination-queue acceptance, not application receipt, execution or durable storage.
  • Timeouts can occur after an effect. There is no automatic retry, reconnect, replay or remote-host transport.

The maintained walkthrough builds matching local NWM3 development artifacts labeled Python 0.3.0.dev0 and Node 0.3.0-dev.0; this does not imply registry availability. Released 0.2.x artifacts use AR2 and are not compatible with this NWM3 guide. Start with local candidate setup, then consult the Python and Node API, CLI and configuration reference.
