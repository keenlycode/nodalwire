Upward native disclosure

BottomNavigation / nw-bottom-navigation remains a reusable Adapter → Base component for an authored native details, summary and navigation panel. The panel opens upward with bounded scrolling; enhancement synchronizes expanded state and Escape restores summary focus.

Embedding MenuStack uses auto height and caller-owned scrolling to avoid competing vertical scroll areas. The design shell no longer instantiates this full-width bar: the bottom-left Menu ButtonPin controls its single combined MenuStack instead. Reusable component files and APIs are preserved.
