What you need

NodalWire is a loopback-only byte relay for local applications. This walkthrough uses matching NodalWire Python and Node.js clients at version 0.2.0. Use Python 3.12 or newer and Node.js 24; the Node SDK uses Deno as a development task runner, not as its runtime. You will also need uv, pnpm, and Deno for the source-checkout setup below.

Set up the source checkout

The repository contains the matching Python relay and Node SDK. From its root, sync the Python environment, then build the Node SDK from its own directory:

{% set setup_example %}uv sync --locked cd src/nodalwire/client/node pnpm install --frozen-lockfile --store-dir ./node_modules/.pnpm-store deno task build cd ../../../.. {% endset %}{{ code_block(setup_example, 'terminal', 'shell') }}

The Node build creates src/nodalwire/client/node/dist/index.js; the example below imports that checkout-local build. The SDK's native zeromq install script is required; if your pnpm policy requires script approval, allow only zeromq. A published npm package is not required for this source-checkout path.

Start the local relay

In a terminal at the repository root, generate and export an administrator token yourself, then start the relay. Keep this terminal running. The default data and administration endpoints are 127.0.0.1:5555 and 127.0.0.1:5556; this example uses the default data endpoint. Configuration is memory-only when no config file is supplied. To choose other endpoints, configure them in a TOML file and pass it with --config; serve has no endpoint command-line option.

{% set relay_example %}export NODALWIRE_ADMIN_TOKEN="$(uv run --locked python -c 'import secrets; print(secrets.token_urlsafe(32))')" uv run --locked python -m nodalwire serve {% endset %}{{ code_block(relay_example, 'terminal', 'shell') }}

The token is required at startup; the relay does not generate one for you. Keep it private and do not reuse a demo value as a production secret. The administrator token grants local administrative authority, not client identity.

Exchange bytes between Python and Node.js

Save the following Python example as python-echo.py in the repository root. In a second terminal, run uv run --locked python python-echo.py. It connects to the running relay, prints a readiness line, receives one message, and replies to the sender reported by the relay.

{% set python_example %}import asyncio import os from nodalwire import Node async def main(): endpoint = os.environ.get("NODALWIRE_ENDPOINT", "tcp://127.0.0.1:5555") async with await Node.connect("python-echo", endpoint) as echo: print("Python echo ready", flush=True) message = await asyncio.wait_for(echo.receive(), timeout=15) assert message.sender == "node-client" assert message.network == "default" assert message.payload == b"hello from Node\x00" await echo.send( message.sender, b"reply from Python\xff", network=message.network, ) print("Python received the Node message and replied", flush=True) asyncio.run(main()) {% endset %}{{ code_block(python_example, 'python-echo.py', 'python') }}

Save this Node.js example as node-exchange.mjs in the repository root. In a third terminal, run node node-exchange.mjs after the Python echo prints its readiness line. The import uses the built SDK in this checkout; use the same client version as the relay.

{% set javascript_example %}import assert from "node:assert/strict"; import { Node } from "./src/nodalwire/client/node/dist/index.js"; const endpoint = process.env.NODALWIRE_ENDPOINT ?? "tcp://127.0.0.1:5555"; const client = await Node.connect("node-client", endpoint); try { await client.send("python-echo", new TextEncoder().encode("hello from Node\0")); const reply = await client.receive({ signal: AbortSignal.timeout(5000) }); assert.equal(reply.sender, "python-echo"); assert.equal(reply.network, "default"); const expected = new Uint8Array([...new TextEncoder().encode("reply from Python"), 0xff]); assert.deepEqual(reply.payload, expected); console.log("Node received the Python reply including byte 0xff"); } finally { await client.close(); } {% endset %}{{ code_block(javascript_example, 'node-exchange.mjs', 'javascript') }}

Expected output includes Python echo ready, followed by the Python receipt/reply line and a Node line confirming the reply. Both peers use the open default network here. A protected default network admits a client with no memberships; each client must explicitly join it using its join credential before sending or receiving there. A network join credential does not grant administration, and the administrator token is not a join credential. Neither proves peer identity. Bearer authentication is not encryption.

A successful send means the destination's native queue accepted the bytes; it does not prove that the peer received or processed them. This example checks the actual reply. Continue with the networks guide, request/reply guide, security guide, and API reference.
