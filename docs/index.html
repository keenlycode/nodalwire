A byte relay for local applications

Connect trusted local Python and Node.js applications through a bounded, loopback-only relay with explicit network membership and separate administration.

NodalWire moves opaque bytes between named connections. Use it for local agent tools, small services and cooperating processes that need an explicit routing boundary without an application-specific message format.

Credentials grant permission, not identity. Loopback bearer authentication is not encryption or protection from the same user or root.

Operate explicitly

Supply an administrator token before starting the relay. Keep configuration policy separate from live connections and membership.

Administration reference

What it does—and does not promise

  • Python and Node.js clients exchange binary payloads through a matching 0.2.0 relay.
  • Declared networks are open unless protected; a protected default needs an explicit join.
  • A send receipt means native destination-queue acceptance, not application receipt, execution or durable storage.
  • Timeouts can occur after an effect. There is no automatic retry, reconnect, replay or remote-host transport.
