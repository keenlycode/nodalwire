Getting Started

Send a message from Node.js to Python and get a reply.

1. Set up

You need Python 3.12+, Node.js 24, uv and pnpm. Open a terminal at the root of a NodalWire 0.2.0 source checkout and run:

terminalshell
uv sync --locked
pnpm -C src/nodalwire/client/node install --frozen-lockfile
pnpm -C src/nodalwire/client/node exec tsc

Run all commands below from this same repository root.

About the Node.js setup

These commands build the matching SDK in this checkout; no published npm package or Deno installation is needed. The Node.js example imports that local build. If pnpm asks for install-script approval, allow only zeromq, which needs its native binding.

2. Start the relay — Terminal 1

Create a private administrator token, then start the relay. Leave it running.

terminal 1shell
export NODALWIRE_ADMIN_TOKEN="$(uv run python -c 'import secrets; print(secrets.token_urlsafe(32))')"
uv run nodalwire serve

The token is required to start the relay, but these clients do not need it. This example uses the default local endpoint and an open default network. Do not start a second relay if one is already using these ports.

3. Run Python — Terminal 2

Save this as python-echo.py in the repository root.

python-echo.pypython
import asyncio
import os

from nodalwire import Node


async def main():
    endpoint = os.getenv("NODALWIRE_ENDPOINT", "tcp://127.0.0.1:5555")
    async with await Node.connect("python-echo", endpoint) as echo:
        print("Python is ready", flush=True)
        message = await asyncio.wait_for(echo.receive(), timeout=120)
        print(message.payload.decode())
        await echo.send(message.sender, b"hello from Python")


asyncio.run(main())

Open a second terminal and run:

terminal 2shell
uv run python python-echo.py

Wait for Python is ready, then run Node.js in the next step.

4. Run Node.js — Terminal 3

Save this as node-exchange.mjs in the repository root.

node-exchange.mjsjavascript
import { Node } from "./src/nodalwire/client/node/dist/index.js";

const endpoint = process.env.NODALWIRE_ENDPOINT ?? "tcp://127.0.0.1:5555";
const client = await Node.connect("node-client", endpoint);
try {
  await client.send("python-echo", new TextEncoder().encode("hello from Node"));
  const reply = await client.receive({ signal: AbortSignal.timeout(5000) });
  console.log(new TextDecoder().decode(reply.payload));
} finally {
  await client.close();
}

Open a third terminal and run:

terminal 3shell
node node-exchange.mjs

Python prints hello from Node and Node.js prints hello from Python. Both clients then exit; the relay stays running. Press Ctrl-C in Terminal 1 when you are finished with your relay.

If the exchange does not finish

Python waits up to two minutes for the message; Node.js waits up to five seconds for the reply. If either times out, check the relay, restart Python, wait for its readiness line, then run Node.js again. These examples use 127.0.0.1:5555 unless NODALWIRE_ENDPOINT is set. An existing protected network needs a join credential; see the networks guide.

Next steps

You have exchanged bytes between two local applications. The reply confirms that Python handled the message; sending alone does not confirm processing. Continue with networks, request/reply, or the API reference. Read security before sharing credentials: they grant permission, not peer identity or encryption.
