Top Navigation

Reusable normal-flow navigation; the design shell now uses a floating ButtonPin and MenuStack.

Normal document flow

TopNavigation / nw-top-navigation remains a reusable Adapter → Base component for authored native navigation in normal document flow. It does not stick to the viewport or generate essential links with JavaScript.

Compose native nav and links inside the host. When embedding MenuStack, set --nw-menu-stack-height:auto so it does not reserve a standalone viewport. The design shell intentionally does not instantiate this bar: its single shared hierarchy is available from the floating Menu button.
