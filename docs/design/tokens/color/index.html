01 / Color palette

Adaptive + extension · 10 families × 5 shades

Start with the available colors before assigning interface roles. Adaptive’s GNOME palette foundations appear in their original shade order. The proposed pink family is a NodalWire extension, not part of the original palette.

Palette first. Semantics second.

02 / Semantic colors

Foundations → semantic roles

Every semantic role references the palette. Note and warning surfaces are derived tints: Color.js mixes the stated palette color with palette.light.1 in OKLCH, maps to sRGB, and resolves the final hex at build time. Recipes are proposals; no color library is shipped to the browser.
